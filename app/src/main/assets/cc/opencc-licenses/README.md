The lyric search converter uses the tw2s normalization, segmentation and conversion dictionaries
from opencc-js 1.4.1, matching the desktop's OpenCC.Converter({from:'tw', to:'cn'}).

Upstream: https://github.com/nk2028/opencc-js
Data: https://github.com/BYVoid/OpenCC
The included notices and Apache 2.0 license apply to the dictionaries.
Only the lyric search keyword is converted; display text uses the existing app converter.
